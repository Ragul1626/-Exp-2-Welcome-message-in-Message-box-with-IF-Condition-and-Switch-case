# UiPath Conditional Logic Demo – Ragul M

This repository contains a simple **UiPath workflow** that demonstrates basic **decision-making** using **IF** and **SWITCH** activities.

---

## 🧩 Project Overview

This project shows how to:

- Get user input using an **Input Dialog**  
- Use an **IF condition** to check for a specific name  
- Use a **SWITCH activity** to handle multiple name-based responses  

### 🛠️ Built With
- **UiPath Studio**
- Demonstrates:
  - Conditional logic (`IF`)
  - Branching logic (`SWITCH`)

A perfect **beginner learning project** to understand UiPath decision-making.
